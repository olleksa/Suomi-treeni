Suomi-treeni - Приложение для изучения финского языка: 
фразы с переводом на русский, повторение по интервалам, 
диалоги, спряжение глаголов, числа на слух, тексты для чтения и подготовка к экзамену YKI (средний уровень). 

https://olleksa.github.io/Suomi-treeni/

Работает в браузере, поэтому подходит для любого устройства: компьютера, iPhone, iPad и телефона на Android. 
Устанавливается на главный экран и работает без интернета.

Как добавить на главный экран
Так приложение открывается во весь экран, как обычное, и работает без интернета.
iPhone и iPad

    Откройте ссылку на приложение в Safari.
    Нажмите «Поделиться» — квадрат со стрелкой вверх (на iPhone внизу экрана, на iPad вверху). Если кнопки не видно, нажмите «…» в адресной строке.
    Прокрутите меню и выберите «На экран „Домой“».
    Нажмите «Добавить». Значок появится на главном экране — открывайте приложение с него.

Android (Chrome)

    Откройте ссылку в Chrome.
    Нажмите меню «⋮» справа вверху.
    Выберите «Установить приложение» (или «Добавить на главный экран») и подтвердите.
